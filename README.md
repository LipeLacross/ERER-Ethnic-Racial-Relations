# ERER-Ethnic-Racial-Relations

Slidev-powered academic presentation on Afro-Brazilian history, resistance, and identity for the ERER course. Built with Markdown & Vue, deployed via GitHub Pages.

## Structure

```
ERER-Ethnic-Racial-Relations/
├── apt-1/                      # Atividade 1 — Tema 3 (Escravização, Resistência e Liberdade)
│   ├── slides.md               # Painel único 16:9 (8 itens obrigatórios)
│   ├── style.css               # Tema custom ocre/dourado
│   ├── public/images/          # Imagens locais
│   ├── painel-erer-tema3.pdf   # Export PDF
│   ├── painel-erer-tema3.pptx  # Export PPTX (imagem)
│   └── package.json            # Scripts dev/build/export
└── README.md
```

## Quick start

```bash
cd apt-1
npm install
npm run dev        # preview
npm run export     # pdf
npm run export:pptx # pptx
```
